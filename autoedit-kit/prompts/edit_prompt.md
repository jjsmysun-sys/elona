# 편집자 프롬프트 — plan.json 작성 규칙

원본을 받으면 `analyze` → **이 문서대로 plan.json 다듬기** → `render --preview` → 프레임 검수 → 최종 렌더.
plan.json의 모든 시간은 **원본 영상 기준 초**다.

## 0. 작업 순서 (묻지 말고 끝까지)
1. `W/transcript.txt`를 처음부터 끝까지 읽는다. 대충 훑지 않는다.
2. 영상의 **약속(한 줄 요약)**을 정한다 → intro 타이틀, 쇼츠 헤드라인, 제목 제안의 기준.
3. remove → fixes → keywords → intro → fx → shorts 순서로 채운다.
4. 미리보기 렌더 후 fx 시점 프레임을 직접 보고 고친다.

## 1. remove (컷)
- 같은 말을 다시 한 경우 → **앞 테이크 삭제**, 뒤 테이크 유지
- "어… 음… 그러니까…"만 있는 구간, 말이 꼬여서 다시 시작한 문장
- 촬영 시작/종료 잡담("녹화되나?", "다시 할게요")
- 주제와 무관한 2문장 이상의 탈선
- 형식: `[[시작, 끝], ...]`. 문장 경계에서 0.05초 여유를 둔다.

## 2. fixes (STT 교정)
명리·운세 용어가 특히 잘 틀린다. 문맥으로 판단해 교정:
일간, 일주, 월지, 재성, 관성, 인성, 식상, 비겁, 식신생재, 상관견관, 대운, 세운, 용신, 희신, 기신, 합충, 공망, 도화살, 역마살, 화개살, 백호살, 괴강살, 자미두수, 기문둔갑, 육효, 타로, 메이저 아르카나, 갑목/을목/병화/정화/무토/기토/경금/신금/임수/계수
투자(ELONA/news): 종목명, 티커, 숫자 단위(억/조/%) 꼭 확인.

## 3. keywords (자막 하이라이트, 15~30개)
- 핵심 개념어, 숫자+단위(“40세”, “3가지”, “70%”), 감정 단어(“대박”, “조심”, “위험”)
- 한 글자 단어 금지(오탐 많음). 조사 붙은 형태 말고 원형으로.

## 4. intro (첫 3초 훅)
`{"title": "12자 내외 약속", "sub": "보조 문구"}`
- 좋은 예: "재물운 터지는 사주" / "3가지 특징", "이 시기엔 절대 이직 금지" / "대운 바뀌는 신호"
- 나쁜 예: "오늘의 영상", "사주 이야기"

## 5. fx 카탈로그 (모션그래픽)
| type | 파라미터 | 언제 | 빈도 |
|---|---|---|---|
| `intro` | (plan.intro로 지정) | 0초 | 1 |
| `lower_third` | name, title | 첫 자기소개 | 1 |
| `chapter` | num, title | "첫 번째/다음으로/마지막으로" 주제 전환 | 주제마다 |
| `list` | title, items[], step | "세 가지" 등 나열 예고 직후 | 1~2 |
| `keyword` | text(2~6자), y | 핵심 개념 처음 등장 | 15~25초에 1회 |
| `stat` | value, label | 숫자가 핵심일 때(나이, %, 금액) | 1~3 |
| `impact` | text, punch(기본 true) | 펀치라인·반전·충격 | 영상 전체 2~3회 |
| `quote` | text, by, wrap | 핵심 문장·격언 (mystic에 잘 맞음) | 1~2 |
| `text` | text, pos(top/bottom) | 보충 설명, 주의 문구, 출처 | 필요 시 |
| `cta` | text(다음 영상 안내) | "구독" 언급 or 끝 20초 전 | 1 |
| `image` | path, mode(pip/full), dur | 사용자가 준 이미지/차트 | 필요 시 |

공통 옵션: `dur`(초), `sfx`(효과음 이름 또는 "none"), `skip: true`(자동 제안 무시).
- analyze가 넣은 `"auto": true` 항목은 **반드시 검토**: title/items/name을 채우거나 `skip: true`.
- 중앙형 fx(chapter/list/keyword/stat/impact/quote)는 서로 최소 1.5초 간격. 겹치면 렌더러가 앞의 것을 자동으로 줄인다.
- `impact`는 해당 지점에 영상 펀치 줌(1.28~1.35배)이 자동 적용된다.
- 과하면 싸 보인다: 10분 영상 기준 fx 총 25~40개가 상한.

## 6. 효과음 (sfx/)
whoosh(전환) · swoosh(짧은 휙) · pop(등장) · tick(리스트) · click(버튼) · ding(포인트) · bell(신비로운 종) · shimmer(반짝임) · impact(붐) · riser(긴장 상승) · typing(타자) · boing(웃음) · news_sting(정보형 스팅)
스타일별 기본 매핑은 `styles.json`의 `sfx`. 특정 fx만 바꾸려면 `"sfx": "bell"`.

## 7. shorts (2~4개)
`{"s": 원본초, "e": 원본초, "headline": "1줄\n2줄", "highlight": "강조단어", "layout": "square|full", "keywords": []}`
- 25~58초(컷 반영 후). **첫 문장이 훅**(질문·충격·숫자·반전)인 구간
- 앞 맥락 없이 이해되는 구간만. "아까 말한 것처럼"으로 시작하면 탈락
- headline: 줄당 10~12자, 2줄. 1줄=상황, 2줄=결과/약속. 예: "마흔에 인생이\n바뀌는 사주"
- layout: 기본 square(상단 헤드라인/중앙 정사각 영상/하단 자막). 세로 원본이거나 얼굴 클로즈업 위주면 full

## 8. 템포 / 줌
- `--tight tight`: 정보형·쇼츠 위주(무음 0.3초부터 컷), `normal`: 일반, `loose`: 상담·감성(호흡 유지)
- segments의 zoom은 1.0/1.1/1.22 자동 교차(점프컷 리듬). 강조 문장 구간은 수동으로 최대값으로.

## 9. 검수 체크리스트 (프리뷰 프레임)
- [ ] 자막이 fx와 겹치거나 얼굴(턱 아래)을 가리지 않는다
- [ ] 텍스트가 화면 밖으로 잘리지 않는다 (긴 chapter title은 14자 이내)
- [ ] 쇼츠 헤드라인이 fx/자막과 겹치지 않는다
- [ ] `python autoedit.py check out/long.mp4` → av_diff < 0.1, lufs ≈ -14
- [ ] chapters.txt 첫 줄이 00:00, 챕터 간격 10초 이상

## 10. 전달 메시지 형식
1~2문장 + `원본 12:30 → 편집 9:48`, 쇼츠 N개, 제목 제안 1줄. 파일: long.mp4, shorts_XX.mp4, long.srt, chapters.txt
